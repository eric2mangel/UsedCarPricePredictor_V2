## Description 📌
Ce projet analyse les prix des voitures d'occasion sur le site **Autoscout24** à l'aide de trois notebooks distincts :

1. **Exploratory Data Analysis (EDA)** : Exploration et visualisation des données pour comprendre les tendances du marché.
2. **Modélisation classique** : Utilisation d'algorithmes de machine learning standards pour prédire les prix des véhicules.
3. **Modélisation mixte (TF-IDF + ML)** : Extraction des marques, modèles, versions et couleurs via un modèle TF-IDF, combiné avec un algorithme de machine learning classique pour affiner la prédiction.



## Installation 🚀
Clonez le dépôt et installez les dépendances :
```sh
git clone https://github.com/eric2mangel/UsedCarPricePredictor_V2.git
cd UsedCarPricePredictor_V2
pip install -r requirements.txt
```

## Utilisation 🛠️
Lancez les notebooks pour explorer l'analyse et l'entraînement des modèles :
```sh
jupyter notebook
```

## Technologies utilisées 🛠️
- Python 3.12.10
- Pandas, NumPy, Matplotlib, Seaborn (EDA)
- Scikit-Learn (modélisation classique)
- TensorFlow/Keras (TF-IDF)
